# Revive IV Lounge: Demo Website

A one-page demo website for **Revive IV Lounge**, a *fictional* IV hydration clinic in Canton, GA.
Built as a portfolio piece by Reese Ballard to show local healthcare businesses what a modern, mobile-first site can look like.

> This is not a real business. All names, prices, reviews, addresses and phone numbers are placeholders.

## What's inside

- `index.html`: page content (hero, treatments, why choose us, sample reviews, FAQ, booking form, footer)
- `styles.css`: mobile-first styles (soft teal `#2A9D8F`, warm white `#FAF7F2`, deep navy `#1D3557`, Plus Jakarta Sans)
- `script.js`: mobile menu, one-at-a-time FAQ, booking form validation (demo only, nothing is sent), scroll fade-ins

No frameworks and no build step. Any static host (Vercel, Netlify, GitHub Pages) can serve it as-is.

## Run it locally

Open `index.html` in a browser.
